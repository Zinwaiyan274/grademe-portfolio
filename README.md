Welcome to my **GradeMe Portfolio** — a collection of C programming exercises that I have completed and validated through the GradeMe grader.

## 🎯 Purpose

The main purpose of this repository is to practice **system-level C programming from scratch** and develop strong programming fundamentals through hands-on problem solving.

I am focusing on understanding how things work at a low level rather than simply memorizing solutions or relying on high-level abstractions.

Every exercise is an opportunity to improve my understanding of C, strengthen my problem-solving ability, and become more comfortable working close to the system.

## 🧠 Practice Philosophy

I am intentionally practicing these exercises under strict conditions:

* 🚫 No AI-generated solutions
* 🚫 No browsing for solutions
* 🚫 No copying solutions from other repositories
* ✅ Solutions are crafted independently
* ✅ Problems are solved through my own reasoning
* ✅ Solutions are tested and validated by GradeMe
* ✅ Errors are debugged and corrected independently

The goal is not just to make the program pass the grader, but to understand **why the solution works**.

## 🔧 Development Approach

For each exercise, my general workflow is:

1. Read and understand the requirements.
2. Identify the expected behavior.
3. Think about the problem before writing code.
4. Design the solution independently.
5. Implement the solution in C.
6. Compile and test the program.
7. Debug any errors.
8. Improve the implementation when necessary.
9. Submit the exercise to GradeMe.
10. Record it as validated after successful testing.
